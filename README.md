# AA Analyzer

Портативный анализатор звука для Windows: показывает спектр, громкость и фазу
системного звука или сетевого потока (Icecast / HLS) в реальном времени. Ничего
не нужно устанавливать: ни драйвера, ни виртуального аудиокабеля.

## Что умеет

### Источники звука

- **Устройство** — системный микс выбранного устройства вывода (WASAPI loopback,
  NAudio). Воспроизведение в колонках или наушниках не нарушается.
- **Поток** — HTTP/HTTPS-адрес Icecast или HLS (`.m3u8`), декодирует LibVLC.
  Список адресов — выпадающий, с историей на 60 последних открытых потоков и
  кнопкой «Очистить». История хранится в `Data\stream-history.json`.
- Статус-бар показывает, что происходит при открытии потока: подключение,
  буферизация с процентами, работа. Справа — диагностика: fps, задержка доставки
  кадра в интерфейс, время отрисовки и число потерянных буферов.
- LibVLC загружается в фоне при запуске приложения, поэтому первый поток
  подключается быстрее.

### Панель индикаторов (слева)

- Peak-индикаторы каналов L и R со шкалой в дБ (шаг 3 дБ), значениями MAX и NOW и
  лампой перегрузки. Клик по значению или лампе сбрасывает его для обоих каналов.
- LU-индикатор громкости (подпись «I / M / S LUFS» по выбранной метрике). Его
  вертикальная шкала совпадает со шкалой графика Loudness: 0 и минимум
  находятся на тех же высотах, шаг меток 3 LU.
- Горизонтальный индикатор фазы (корреляция L/R от −1 до +1): слева минимум с
  последнего сброса, справа текущее значение.

### Режимы (вкладки)

- **Waterfall** — стерео-водопад: левый канал сверху, правый снизу, ось частот
  внизу с частыми делениями, курсор с подписью частоты. Строки соответствуют
  равным отрезкам звука, высота строки не зависит от частоты кадров.
- **Loudness** — график громкости по времени.
  - Метрики: Momentary, Short-Term, Integrated.
  - Окно: 1 мин … 12 ч; масштаб по Y (Y−/Y+), сдвиг (▼/▲) или автомасштаб.
  - **Target line** (по умолчанию −23 LU) с полосой допуска ±3 LU, как в RTA.
    Значение меняется кнопками −/+ на панели или в настройках.
  - Расчёт по ITU-R BS.1770 (K-взвешивание, абсолютный и относительный пороги).
- **RTA** — анализатор в полосах 1/1, 1/3, 1/6, 1/12 октавы: источник Mono / L / R,
  усреднение (1, 10, 20, …), пиковые «шапочки», целевая линия с полосой.
- **Phase** — фазовый скоп (вектороскоп) с регулировкой усиления.

Кнопки справа в строке вкладок: **СБРОС** (все измерения и графики), **PNG**
(скриншот текущей вкладки в `Screenshots\`), **НАСТРОЙКИ**.

### Настройки и профили

Окно настроек охватывает FFT (размер, окно, шкалы), Waterfall (пороги и
палитра), индикаторы, Loudness, RTA и Phase. Настройки хранятся в профилях
(`Data\profiles.json`): можно сохранить под именем, удалить, назначить профиль
по умолчанию. Изменения кнопками на панелях (метрика, окно, цель, RTA)
сохраняются в профиль по умолчанию автоматически.

## Требования

- Windows 10/11.
- Для запуска готовой сборки ничего не нужно (.NET и LibVLC входят в неё).
- Для сборки из исходников: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
  с поддержкой Windows Desktop (WPF).

## Запуск готовой сборки

Скопируйте папку `release\AAAnalyzer-<версия>` куда угодно и запустите
`AAAnalyzer.exe`. Рядом с программой создаются:

| Путь | Содержимое |
|---|---|
| `Data\profiles.json` | профили настроек |
| `Data\stream-history.json` | история адресов потоков |
| `logs\AAAnalyzer.log` | журнал работы |
| `Screenshots\` | PNG-скриншоты вкладок |

## Сборка из исходников

```powershell
git clone <адрес репозитория>
cd AAAnalyzer

# отладочная сборка и тесты
dotnet build
dotnet test

# запуск без публикации
dotnet run --project src\SystemAudioAnalyzer.App
```

### Портативная сборка (.exe)

```powershell
# версия берётся из VERSION.txt, формат «0.042 - 2026.10.08»
.\release\rebuild.ps1                              # win-x64
.\release\rebuild.ps1 -RuntimeIdentifier win-arm64 # ARM64
```

Скрипт выполняет `dotnet publish` (Release, self-contained, без одного файла) в
`release\AAAnalyzer-<версия>`, убирает лишние локализации (оставляет `en` и `ru`)
и проверяет, что в сборке есть `AAAnalyzer.exe` и `libvlc.dll`. Готовую папку
можно переносить на другой компьютер целиком.

Версия хранится в `VERSION.txt` в виде `a.bbb - yyyy.mm.dd`: `bbb` растёт с
каждым коммитом, `a` — по решению разработчика. История изменений — в
[CHANGELOG.md](CHANGELOG.md).

## Структура репозитория

```text
SystemAudioAnalyzer.sln
src/
  SystemAudioAnalyzer.Core/        движок: захват, уровни, True Peak, LUFS, FFT
  SystemAudioAnalyzer.App/         WPF-интерфейс, источники WASAPI и LibVLC, настройки
  SystemAudioAnalyzer.Diagnostic/  консольная утилита: список устройств вывода
tests/
  SystemAudioAnalyzer.Core.Tests/  тесты движка и измерителей
  SystemAudioAnalyzer.App.Tests/   тесты интерфейсной логики, настроек и отрисовки
release/
  rebuild.ps1                      сборка портативной версии
```

### Как устроен поток данных

```text
WASAPI loopback / LibVLC
  → очередь (~4 с звука)
  → равные порции, воспроизведение по часам аудио (~30 кадров/с)
  → LevelMeter, TruePeak, LoudnessMeter, SpectrumAnalyzer (FFT)
  → AnalysisFrame (неизменяемый снимок)
  → WPF-представления
```

Сетевые источники отдают звук пачками (примерно по полсекунды), поэтому движок
проигрывает его в темпе аудио, а не по мере поступления: кадры идут ровно и
звук не теряется.
