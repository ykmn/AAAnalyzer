# Выравнивание GUI по референс-скриншотам — дизайн

Дата: 2026-10-07. Референс: `reference screenshots/` (Spectrum Tool DSP 3).

## Цель

Привести Waterfall, Loudness, RTA и Peak rail к виду и поведению референса. Диалоги настроек не меняются.

## Решения

- Ширина левой колонки и Peak rail: 130 px (без изменений).
- Waterfall остаётся стерео: L сверху, R снизу (вертикальное разделение).
- Время в Waterfall идёт сверху вниз: новая строка появляется сверху каждой половины, старые сдвигаются вниз.
- Рендер Waterfall переносится на `WriteableBitmap`.

## 1. Компоновка окна

- Левая колонка 130 px: источник, Старт/Стоп, Peak rail. Rail растягивается на всю оставшуюся высоту (вместо фиксированных 320 px).
- Вкладки (Waterfall / Loudness / RTA / Phase) и кнопки Сброс / PNG / Настройки — одна узкая строка поверх графика. Плоский тёмный стиль кнопок, активная вкладка подсвечена.
- Отступы вокруг графиков убираются.

## 2. Peak rail

- Сверху по каналу: значение пика; под ним красный квадрат clip с буквой «C». Клик по clip сбрасывает Overload, клик по значению сбрасывает MAX.
- Слева шкала dB с подписями через 5 dB; справа голубая LUFS-колонка с цифрами (пресеты Broadcast / Full / Custom).
- Снизу крупное LUFS-значение с подписью «LUFS»; подписи каналов L / R / LU.
- Тексты не накладываются при ширине 130 px.

## 3. Waterfall

- Одно полотно, две половины (L сверху, R снизу), в каждой своя ось 20 Hz–20 kHz на всю ширину.
- Каждая половина — буфер `WriteableBitmap` с частотной сеткой в пикселях по ширине. Новая строка пишется в верхний ряд, остальные сдвигаются вниз через `Array.Copy` (`WaterfallBitmapBuffer`, без зависимости от WPF для тестов).
- Курсор: белая вертикаль на обеих половинах, плашка с частотой («10.1 kHz») на самом курсоре. Частотные подписи оси крупнее текущих.
- Окно времени 10 с (как сейчас); высота строки считается от высоты половины.

## 4. Loudness

- Кнопки метрики: Momentary / Short-Term / Integrated / Rolling / Reset.
- Кнопки окна: 1m…12h, Y−, Y+, диапазон. Выбор сразу меняет `Settings.Loudness`.
- Крупное зелёное значение «-11.7 LUFS» справа вверху; подпись кривой («Integrated Loudness») в нижнем правом углу.
- Метки времени сверху, в локальном времени (сейчас UTC). Шаг сетки по Y подстраивается под диапазон.

## 5. RTA

- Подписи частот под столбиками (20, 28, 40 … 20k) и dB слева (0 … −60).
- Сегментированные столбики (LED-лесенка), пик-колпачок, целевая полоса с сеткой поверх.
- Строка над графиком: Mono / L / R и 1/1…1/12 с подсветкой активной; «Avg N ±», «Tgt −36 +». Значения сразу пишутся в настройки.

## 6. Тесты

Чистая логика выносится в классы без WPF и покрывается unit-тестами: раскладка рейла (подписи, шкалы), частотные подписи, сдвиг строк `WaterfallBitmapBuffer`, шаг сетки Loudness, сегментация столбиков RTA. Ручная приёмка на Windows остаётся отдельным пунктом TODO.

## Вне объёма

Диалоги настроек, профили, движок анализа (Core). Phase Scope получает только общий стиль верхней строки.
