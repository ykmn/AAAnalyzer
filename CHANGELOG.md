# Changelog

## 0.035 — 2026-10-07

- Диалог настроек приведён к reference screenshots: шесть страниц Analyzer,
  Waterfall, Meters, Loudness, RTA и Phase, редактирование цветовых градиентов
  через системный Windows ColorDialog и общие действия с профилями.
- Apply/OK меняют только активный снимок; Save/Save as/Default/Delete выполняют
  явные операции с каталогом. Cancel и закрытие окна восстанавливают настройки,
  активные при открытии. README описывает app-local storage и legacy-импорт.

## 0.034 — 2026-10-07

- Настройки Analyzer теперь применяются без перезапуска источника; Waterfall
  использует линейную/логарифмическую шкалу и пользовательскую dB-палитру.
- RTA получил rolling average, наклон, спад и истекающие peak caps; Phase gain
  ограничивает координаты безопасной областью.

## 0.033 — 2026-10-07

- Ограничено окно Integrated LUFS диапазоном 1–3600 секунд на уровне настроек
  и Core API, чтобы ограничить память и вычислительную стоимость агрегации.

## 0.032 — 2026-10-07

- Индикаторы Peak/RMS получили настройки видимости, цвет, шкалу, LUFS-метрику,
  сглаживание атаки/спада и ограниченный по времени peak hold.
- История Loudness теперь поддерживает окно до 12 часов, выбранную метрику,
  пользовательский LUFS-градиент и ручной диапазон по центру/размаху.
- Rolling Integrated LUFS ограничен настраиваемым окном и меняется без
  остановки источника.

## 0.031 — 2026-10-07

- Сохранение через существующий диалог обновляет Default в каталоге профилей;
  настройки сохраняются после перезапуска до перехода диалога на явные операции
  с профилями. Сохранение остальных профилей и совместимый settings.json сохранены.

## 0.030 — 2026-10-07

- Добавлен каталог общих профилей `Data/profiles.json` рядом с приложением:
  Save, Save As, Delete и выбор Default для следующего запуска.
- Настройки из `%LocalAppData%\AAAnalyzer\settings.json` импортируются по полям
  при первом запуске без удаления источника; запись каталога заменяется атомарно,
  повреждённый каталог использует встроенный Default и записывает диагностику.

## 0.029 — 2026-10-07

- Добавлена Core-конфигурация FFT 512–16384 и окон Rectangular, Hann, Hamming,
  Blackman; Hann сохранён по умолчанию для прямых вызовов SpectrumAnalyzer.
- Настройки спектра применяются на worker без перезапуска источника и сброса
  истории измерителей; AnalyzerController передаёт конфигурацию в Core.

## 0.028 — 2026-10-07

- Добавлена расширенная модель и валидация настроек Analyzer, Waterfall, Meters,
  Loudness и RTA; градиенты по умолчанию приведены к reference screenshots.
- Первый Waterfall stop установлен в чёрный `#000000` по подтверждённому скриншоту.

## 0.027 — 2026-10-07

- Составлен пошаговый план реализации полного набора функциональных настроек,
  перестройки DSP без остановки источника и общих профилей приложения.

## 0.026 — 2026-10-07

- Подготовлена спецификация полного набора настроек измерений и общих профилей:
  применение DSP без перезапуска источника, редактируемые градиенты, миграция
  настроек в локальную папку приложения и поведение Apply/Save.

## 0.025 — 2026-10-07

- Исправлен fallback для JSON с отсутствующими вложенными полями; выбор
  Mono/L/R синхронизирован между настройками и radio-кнопками RTA.
- Analyzer floor применяется к нижней границе Waterfall/RTA.

## 0.024 — 2026-10-07

  True Peak; проверены геометрические и transactional сценарии.

## 0.022 — 2026-10-07
